# Flower Illustrations

Place your 7 hand-painted/watercolor flower PNG files here with **exactly** these filenames:

| Filename | Description |
|---|---|
| `pink-lily.png` | Single pink star/lily flower on a long stem |
| `red-poppy.png` | Large red poppy, thick black stem |
| `blue-cornflower.png` | Teal/blue flowers on olive branch spray |
| `pink-wildflower.png` | Pink wildflower spray with buds |
| `sage-leaf.png` | White/sage green leaf branch |
| `pink-ginkgo.png` | Pink ginkgo leaf cluster |
| `yellow-rose.png` | Cream/yellow roses on dark stem |

PNGs should have transparent or dark backgrounds. They are referenced from the app as `/flowers/<filename>`.
