# Wrapper Images

Drop your hand-painted wrapper PNG files here. Each file corresponds to a wrapper variant in the app.

| Filename              | Wrapper variant        | Notes                                      |
|-----------------------|------------------------|--------------------------------------------|
| `paper-wrap.png`      | Matte paper wrap       | The yellow/golden bouquet with a bow goes here |
| `tulle-wrap.png`      | Tulle fan wrap         | Soft gathered mesh wrap                    |
| `cellophane-wrap.png` | Cellophane funnel wrap | Clear gloss wrap with twine & tag          |

## Requirements

- PNG with transparency (alpha channel) recommended so the cream background shows through
- Images should be portrait-oriented — roughly 1:1.4 (width:height) aspect ratio
- They will be displayed at various sizes (60 px tall in the picker card, 360–452 px tall in the canvas)
- The full illustration goes in one file — no need to split into back/front layers
